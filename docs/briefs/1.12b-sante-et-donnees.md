## 1. curl dans l'image

Dockerfile, étage final : `apk add --no-cache ca-certificates curl`. Vérifier en local que `docker run … curl -fsS http://localhost:3000/api/sante` réussit depuis l'intérieur du conteneur, puis supprimer image et conteneur.

## 2. Santé renforcée

`/api/sante` vérifie, avec le client applicatif : `SELECT 1`, puis `has_table_privilege(current_user, 'core_user', 'SELECT')` et `has_table_privilege(current_user, 'core_team', 'INSERT')`, puis qu'il y a 11 lignes dans `core_app`. Réponse 200 `{ ok: true }` si tout passe ; sinon 503 `{ ok: false, raison }` avec une raison courte en français sans détail sensible (« base injoignable », « droits du rôle de l'app incomplets », « catalogue des apps absent »), et le détail dans les logs serveur. Test unitaire de la fonction de décision, e2e conservé.
