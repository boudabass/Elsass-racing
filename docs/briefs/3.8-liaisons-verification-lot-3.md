## 1. Rattacher un fichier venu d'une autre app

`rattacherFichier` refuse un fichier envoyé par un autre membre. C'est voulu pour une saisie. Mais une liaison réutilise le fichier d'une autre app : la photo de pose de Voiture devient une preuve dans Partenaires, et c'est un membre qui ne l'a pas forcément envoyée qui le décide.

- Ajoute dans `src/core/fichiers/fichiers-serveur.ts` `rattacherDepuisSource(client, ctx, { fileId, source: { app, ficheType, ficheId }, cible: { app, ficheType, ficheId, role } })`.
- La fonction vérifie que le fichier est déjà rattaché à la fiche source, dans la même team, puis le rattache à la cible. Sinon, même refus qu'aujourd'hui.
- Test unitaire et contrôle dans `db:verifier-rls` : sans rattachement à la source, refus.
