## 4. Liens d'action : un seul style

Les liens d'action dans le texte ont aujourd'hui 7 styles différents. Par exemple :
- « Rembourser » a un soulignement rouge épais ;
- « Débrief » a un soulignement blanc simple ;
- d'autres ne se soulignent qu'au survol.

Crée `LIEN` dans `src/lib/classes-formulaire.ts` :

```ts
// Lien d'action dans le texte : souligné en permanence (le soulignement dit que c'est un lien), cible de 44 px.
export const LIEN = "cible-tactile inline-flex items-center underline underline-offset-4 decoration-marque decoration-2 hover:text-marque"
```

Applique-le à chaque lien souligné de `src/`, c'est-à-dire chaque `className` qui contient `underline` sur un `<Link>` ou un `<a>`. Pour les trouver :

```
grep -rn 'underline' src --include=*.tsx
```

Règles d'application :
- garde les classes de placement propres à chaque lien (`px-4 pb-3 text-sm`, `justify-self-start sm:col-span-3`…), concaténées après `LIEN` ;
- ne touche pas aux onglets ni aux entrées de menu, qui ne sont pas soulignés ;
- les liens en `hover:underline` seul deviennent `LIEN`, sauf celui de la barre haute (`font-medium hover:underline`), qui est un titre cliquable : laisse-le.
