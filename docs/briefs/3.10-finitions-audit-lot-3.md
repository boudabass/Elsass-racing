## 3. Une seule règle pour les actions

Sur la fiche convention et sur la fiche partenaire :

| Rôle | Style |
|---|---|
| Une action sur la fiche : renouveler, ajouter, saisir, reporter, modifier, masquer | Bouton secondaire (`BOUTON_SECONDAIRE`) |
| Une action qui détruit ou ferme : résilier, supprimer | Bouton secondaire de couleur danger (`BOUTON_DANGER`) |
| Aller vers une autre page ou télécharger | Lien (`LIEN`) |
| L'action principale d'un formulaire ouvert : enregistrer, confirmer | Bouton principal, un seul par formulaire |

- « Ajouter une contrepartie » n'est plus un bouton sur toute la largeur. C'est un bouton secondaire, à sa taille.
- « Supprimer » d'une preuve passe en danger.
- Liste dans le compte-rendu ce que tu as changé, écran par écran.
